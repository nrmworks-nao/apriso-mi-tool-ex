============================================
  Apriso MI設定ツール (AprisoMIToolEx)
============================================

DELMIA Apriso の Machine Integrator（MI）の設定を、Apriso の DB を直接参照して
閲覧・編集するツールです。

  - スクリプト            : 閲覧（大きなエディタ表示、横断検索、差分比較、ファイル出力）と、
                            編集モードでのソースの編集・DB への書き戻し（保存前に文法チェック）
  - アクショングループの
    ポイント設定          : 閲覧と編集（一括編集、CSV/Excel 入出力、他グループから複製、
                            連番生成、各種チェック）
  - ポイント・データソース: 閲覧のみ

【動作要件】
  OS: Windows 10 以降
  ODBC Driver 17 for SQL Server または ODBC Driver 18 for SQL Server
    （インストールされていない場合は Microsoft のサイトから入手してインストールしてください）
  Python: 不要（exe 版は同梱済み）

【起動方法】
  exe 版   : AprisoMIToolEx.exe をダブルクリックしてください。
  ソース版 : .venv\Scripts\python.exe main.py

【初回の接続設定】
  1. 初回起動時は「接続設定」ダイアログが自動で開きます
     （接続に失敗した場合も自動で開きます。メニュー「ファイル → 接続設定」からも開けます）。
  2. サーバー、データベース（既定 FLX24M）、ODBC ドライバーを指定します。
  3. 認証方式を選びます。
       Windows 認証     : ログオン中の Windows アカウントで接続します。
       SQL Server 認証 : ユーザー名とパスワードを入力します。パスワードは config.json には
                         書かず、Windows 資格情報マネージャーに保存します
                         （サービス名 AprisoMIToolEx、キー「<サーバー>/<ユーザー名>」）。
  4. 自己署名証明書のサーバー等では「サーバー証明書を信頼する」を ON にします。
  5. 「更新者名」に、DB の監査列（CreatedBy / LastUpdatedBy）に記録する表示名を
     入力します（50 文字以内。例: 岸 隼人(ALSI)）。未設定の場合は保存できません。
  6. 「接続テスト」で SELECT 1 が成功することを確認し、OK を押します。

【編集と保存】
  - 起動時は閲覧モードです。ツールバーの「編集モード」を ON にしたときだけ編集できます。
  - 編集内容はすぐには DB に書き込まず、未保存の変更として表に保持します
    （変更セル: 黄、追加行: 緑、削除行: 赤＋取り消し線）。
  - 「保存」で変更プレビュー（実行される SQL も確認可能）を表示し、「実行」で DB に反映します。
    実行直前に backup\ へ更新・削除対象の行（.json）と、元に戻すための SQL（.sql）を出力します。
  - 書き込みは 1 つのトランザクションで行い、1 行でも失敗するとすべて取り消します。
    読み込み後に他で更新された行があった場合も取り消します（再読込してやり直してください）。
  - MI 側への反映には、MI のリフレッシュまたは再起動が必要な場合があります。

【スクリプトの編集と保存】
  - 編集モードが ON のときだけ、スクリプトタブで C# ソース（<Source>）を編集できます。
    入力変数・呼び出しオペレーション・using は編集できません。別ウィンドウは常に読み取り専用です。
  - 未保存の変更があると、見出しのタイトル末尾に「●」が付きます。ツールバーの「保存」で
    文法チェック → 変更プレビュー（接続先、対象、変更前後の差分、文法チェックの結果）→「実行」
    の順に DB（SCRIPT テーブル）へ書き戻します。「元に戻す」で DB から読み込んだ内容に戻ります。
  - 書き換えるのは SCRIPT.Script の <Source> の中身だけで、それ以外の部分（<ScriptId> など）は
    1 文字も変えません。改行コード（CRLF / LF）は元のスクリプトのままにします。
  - 実行直前に backup\ へ更新前の行（.json）と、Script を元に戻すための SQL（.sql）を出力します。
  - 保存しただけでは MI には反映されません。保存後に、Apriso のマシーンインテグレータ設定で
    「マシーンの更新」を実行してください（MI の再起動は不要です）。

【文法チェック】
  - スクリプトタブの「文法チェック」（F7）で、C# コンパイラ（csc.exe）を使って文法をチェック
    します（編集モードでなくても実行できます）。結果はビューアの下の「エラー一覧」に表示され、
    行をダブルクリックすると該当行へ移動します。
  - 使用するコンパイラは、Visual Studio（Build Tools を含む）付属の C# コンパイラ（Roslyn）を
    優先し、なければ Windows 標準の C# コンパイラ
    （%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe）を使います。
    検出されたコンパイラは「ヘルプ → バージョン情報」で確認できます。
  - 別のコンパイラを使う場合は、config.json の compiler.csc_path に csc.exe のパスを指定します
    （タイムアウトは compiler.timeout_seconds、既定 60 秒）。
  - 保存時に文法エラーがある場合は保存できません。コンパイラが見つからない等でチェックできない
    場合は、理由を表示したうえで「チェックなしで保存」するかを確認します。
  - このチェックは Apriso 本体のコンパイルと同一ではありません。MI・Log のメソッド名や引数は
    検査されません。

【フォルダ・ファイル】
  config.json : アプリケーション設定（初回起動時に自動生成）
  backup\     : 更新前データの退避先（自動作成）
  log\        : 操作ログ AprisoMIToolEx_YYYYMM.log（自動作成）
