# 変更指示 001: スクリプトタブの「詳細」を右サイドバーにする

## 0. 作業ルール

`docs/CLAUDE_CODE_指示書.md` の「0. 作業ルール」をそのまま適用する（コードの実行・DB接続は行わない）。
変更は本書に書いた範囲に限り、関係のない箇所を整理・改名しないこと。

## 1. 目的

スクリプトタブでは現在、「詳細（入力変数・呼び出しオペレーション・更新情報）」がコードビューアの**下**に横並びで表示され、コードの表示行数を減らしている。
これを VS Code のセカンダリサイドバーのように、**コードビューアの右側に置く縦長のサイドバー**に変更し、表示／非表示を切り替えられるようにする。

## 2. 変更後のレイアウト

```
┌─ 見出し・操作ボタン ─────────────────────────────── [詳細] ┐
├──────────────────────────────────────────┬───────────────┤
│                                          │ ▼ 入力変数    │
│                                          │  名前 │ 型    │
│   コードビューア                          │  ...          │
│   （サイドバーを閉じると全幅）            │ ▼ 呼び出しOP  │
│                                          │  MANI_...     │
│                                          │ ▼ 更新情報    │
│                                          │  作成者: ...  │
└──────────────────────────────────────────┴───────────────┘
```

## 3. 仕様

### 3.1 サイドバー（gui/script_tab.py）

- `ScriptTab` のコードビューア（`CodeViewerPanel`）と `ScriptInfoPanel` を、水平方向の `QSplitter` に入れる（左: コードビューア、右: サイドバー）。
- コードビューア下の `CollapsibleSection("詳細（…）")` は撤去する。
- `ScriptInfoPanel` を**縦積み**に作り直す。上から「入力変数」「呼び出しオペレーション」「更新情報」の3セクションとし、それぞれを既存の `CollapsibleSection` で包んで個別に折りたためるようにする。
  - 既存の `setMinimumHeight(150)` / `setMaximumHeight(240)` は削除する。
  - 入力変数の表が残りの高さを使い切るようにする（stretch を入力変数に寄せる）。
  - 「更新情報」の `QFormLayout` は幅が狭くても崩れないよう、`setRowWrapPolicy(QFormLayout.RowWrapPolicy.WrapLongRows)` とする。
- サイドバーの幅: 既定 320、最小 220。スプリッターのハンドルをドラッグして変更できる。
- スプリッターの伸縮は、ウィンドウ幅を変えたときにコードビューア側だけが伸び縮みするようにする（`setStretchFactor(0, 1)` / `setStretchFactor(1, 0)`）。
- サイドバーはスプリッターで幅0まで潰せないようにする（`setCollapsible(1, False)`）。非表示は必ず 3.2 の切り替えで行う。

### 3.2 表示／非表示の切り替え

- 見出しバー（`panelToolBar`）の**右端**に、チェック可能なボタン「詳細」を追加する（押されている状態 = 表示中）。
- ショートカットは **Ctrl+Alt+B**（VS Code のセカンダリサイドバーと同じ）。
- メニュー「表示(V)」に、チェック可能な項目「スクリプト詳細サイドバー (Ctrl+Alt+B)」を追加する。ボタン・メニュー・ショートカットの状態は常に一致させる。
- 非表示にするとコードビューアが全幅になる。再表示すると、非表示にする前の幅に戻る。

### 3.3 別ウィンドウ（ScriptWindow）

- 「別ウィンドウで開く」で開く `ScriptWindow` にも同じサイドバーと切り替えボタン・ショートカットを付ける。
- 別ウィンドウの初期状態は**非表示**とする（コードを広く見るためのウィンドウのため）。別ウィンドウでの切り替えは、そのウィンドウだけに作用し、設定には保存しない。

### 3.4 設定の保存（core/config_manager.py）

`WindowConfig` に次の2項目を追加し、メインウィンドウのスクリプトタブの状態を保存・復元する。

| キー | 型 | 既定値 | 内容 |
|---|---|---|---|
| `script_sidebar_visible` | bool | `true` | サイドバーを表示するか |
| `script_sidebar_width` | int | `320` | サイドバーの幅（px） |

- 保存のタイミングは、既存のウィンドウ位置・スプリッター位置の保存と同じ（終了時）とする。
- 既存の `config.json` にキーがない場合は既定値で補う（既存の読み込み処理の仕組みに合わせる）。

### 3.5 スタイル（gui/styles.py）

- サイドバーの背景はパネル背景（白）、コードビューアとの境界は既存のスプリッターハンドルのスタイルに合わせる。
- 「詳細」ボタンの押下中（checked）の見た目を定義する（押下中: アクセント色の背景、非押下: 既存ボタンより控えめな見た目）。
- スタイルは `styles.py` に集約し、`script_tab.py` には `objectName` の設定のみを書く。

## 4. 変更対象ファイル

- `gui/script_tab.py`
- `gui/main_window.py`（表示メニューの項目追加、設定の保存・復元）
- `core/config_manager.py`
- `gui/styles.py`

上記以外のファイルは変更しない。変更が必要だと判断した場合は、理由を添えて質問すること。
